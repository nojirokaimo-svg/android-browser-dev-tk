# Android Browser Dev TK

Personal Android browser development repository based on Chromium.

This repository contains custom Android browser changes, build tooling, and experimental UI/feature work. It is an independent modified project and is not an official release of any upstream project.

## Development

Active development is carried out on the `codex/kiwi-ui-port` branch.

The project uses Chromium with upstream work derived from:

- [Titanium Browser for Android](https://github.com/jqssun/android-titanium-browser)
- [Vanadium](https://github.com/GrapheneOS/Vanadium)
- [Chromium](https://chromium.googlesource.com/chromium/src/)

Custom changes are maintained separately from the upstream projects.
